# 🔐 Day 10 — Security Policies | Cyber Security Internship (Veda Technology)

## 📌 Objective
Understand organizational security controls by creating a basic cybersecurity policy for a small organization.

## 🛠️ Tools Used
- Google Docs (policy drafting)

## 📄 Deliverable
[`Cybersecurity_Policy.md`](./Cybersecurity_Policy.md) — Basic Cybersecurity Policy

## 🧭 Approach
1. Studied what a security policy is and why organizations need one.
2. Identified the key risk areas for a small organization: weak passwords, unmanaged devices, phishing emails and slow incident response.
3. Wrote clear, enforceable rules for each area, plus data protection, access control, training and enforcement.
4. Added a step-by-step incident reporting workflow and an acknowledgement section.

## 📚 Policy Sections
| Section | Key Controls |
|---|---|
| Password Policy | 12+ chars, MFA, password manager, no reuse |
| Device Security | Encryption, updates, antivirus, lost-device reporting |
| Email & Internet | Phishing awareness, no credential sharing, VPN on public Wi-Fi |
| Data Protection | Classification, backups (3-2-1) |
| Access Control | Least privilege, offboarding |
| Incident Reporting | Identify → Report → Contain → Investigate → Recover → Review |

## ✅ Outcome
Produced a practical, easy-to-follow security policy that a small organization can adopt to reduce human-error risks and respond quickly to incidents.

## 💬 Interview Q&A
**What is a security policy?** A formal document defining rules and procedures for protecting an organization's information and systems.

**Why are policies important?** They set consistent expectations, reduce human-error risk, support compliance, and enable a fast, coordinated incident response.
